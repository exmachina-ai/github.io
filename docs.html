Как пользоваться каталогом

Если нужен быстрый расчёт — открывайте инструмент из каталога. Если нужен инженерный контекст — переходите в связанный модуль. Каждый встроенный калькулятор находится внутри модуля не случайно: формулы без понимания ограничений легко превращаются в источник ошибочных проектных решений.

  • Для анализа распределения потребления используйте Distribution / Percentile Diagnostic в Модуле 1.
  • Для базовой проверки петли Kanban используйте Kanban Loop Calculator в Модуле 2.
  • Для подготовки чертежей упаковки используйте HU Drawing Generator как скачиваемый Excel/VBA-инструмент.
