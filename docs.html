HU Drawing Generator

HU Drawing Generator — это инженерный инструмент на базе Excel для автоматической генерации стандартизированных чертежей упаковки (Handling Units) из массива данных PFEP и BOM.

Инструмент решает задачу синхронизации мастер-данных упаковки (PFEP, BOM) и инженерной документации без ручной переделки и проверки версий.

Инженерная проблема

В классическом процессе чертежи упаковки создаются вручную, что приводит к рассинхронизации между логистическими данными и инженерной документацией.

Ошибки на этом уровне масштабируются: MIX-HU, неверные габариты, устаревшие версии чертежей, ручные правки в разных местах разными людьми.

Инженерное решение

В EXMACHINA мы исходим из принципа: чертёж не рисуется — он вычисляется.

HU Drawing Generator использует данные как единый источник истины. Вся логика построения управляется параметрами, не жёсткой формой.

Как это работает

Excel (HU_DATA) → VBA-логика → API КОМПАС-3D → готовый стандартизированный чертёж.

Внешний вид и структура чертежа не «зашиты» жёстко — параметры могут быть адаптированы под требования конкретного проекта.

Роль инструмента в EXMACHINA

HU Drawing Generator — это не отдельный макрос и не утилита. Это первый уровень автоматизации в инженерной цепи EXMACHINA-AI.

Он демонстрирует базовый принцип проекта: процессы, данные и инженерные решения должны быть связаны детерминированной логикой, а не ручной работой.
