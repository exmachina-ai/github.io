# EXMACHINA-AI

Публичный сайт инженерного проекта **EXMACHINA-AI** — методология, обучающие модули, справочник терминов, публикации и инструменты по внутренней логистике автомобильного производства.

**Сайт:** https://exmachina-ai.ru

---

## Обзор проекта

**EXMACHINA-AI** — открытая инженерная платформа по проектированию и диагностике процессов внутренней логистики автомобильного производства.

В основе проекта — методология E2E-проектирования внутренней логистики через систему 9 слоёв: от терминологии, производственной программы и мастер-данных до хранения, снабжения линии, транспорта, цифрового управления, метрик и аудита.

Проект развивается в трёх направлениях:

- **Методология** — причинно-следственная модель проектирования процессов внутренней логистики.
- **Обучающие модули** — самостоятельные учебные страницы, раскрывающие ключевые понятия методологии на инженерных примерах.
- **Инструменты и справочник** — интерактивные мини-инструменты, Excel/VBA-решения, словарь терминов и материалы для практического применения.

Долгосрочное направление проекта — предиктивная система на базе SQL/ML/LLM для диагностики рисков shortage, перегрузки маршрутов, рассинхронизации материального и цифрового потока. Эта система рассматривается как будущая надстройка над методологической базой, а не как текущий готовый продукт.

## Основные разделы сайта

### Главная

Краткое описание проекта, текущих направлений и будущей предиктивной системы.

### Методология

Методология E2E-проектирования внутренней логистики автомобильного производства. Основная идея — проектировать не отдельные зоны склада или маршруты, а причинно-следственную систему.

### Обучение

Каталог обучающих модулей. Каждый модуль является самостоятельной страницей и раскрывает отдельный инженерный вопрос:

* распределения, вариативность и ошибка среднего;
* Push, Pull и Kanban;
* выбор концепта снабжения линии;
* упаковка и грузовые единицы;
* хранение, топология и ёмкость;
* транспорт и производительность;
* цифровое управление, метрики и аудит.

### Справочник

Словарь терминов, поддерживающий онтологию проекта. Термины должны быть связаны с методологией, обучающими модулями и инструментами.

### Документы и инструменты

Раздел для инженерных документов, PDF-версий материалов, Excel/VBA-инструментов и ссылок на встроенные HTML-инструменты.

### Публикации

Инженерные статьи, эссе и методологические материалы по внутренней логистике, CKD/SKD, проектированию потоков и управлению логистическими системами.

## Дизайн и стиль

Сайт использует единую визуальную систему:

* тёмная индустриальная тема;
* оранжевый акцент `#e06820`;
* карточная сетка;
* технические бейджи;
* longform-страницы для методологических текстов;
* адаптивная вёрстка для мобильных, планшетов и десктопа.

При доработке сайта важно не создавать отдельный визуальный язык для новых разделов. Новые страницы должны переиспользовать существующие классы и CSS-переменные из `style.css`.


## Работа с изменениями

Рекомендуемый порядок для крупных изменений:

1. Создать отдельную ветку.
2. Внести изменения небольшими логическими шагами.
3. Проверить diff.
4. Проверить локально ссылки, навигацию и адаптивность.
5. Обновить `sitemap.xml`, если добавлены новые публичные страницы.
6. Создать pull request или выполнить merge в `main`.

Пример имени ветки:

```text
feature/learning-module-01
```

Пример commit message:

```text
feat: add learning section and first module
```
