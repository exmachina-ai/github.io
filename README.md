# EXMACHINA-AI Landing Page

Landing page для **EXMACHINA-AI** — инженерного проекта по автоматизации производственной логистики CKD.

**Сайт:** https://exmachina-ai.ru

---

## 📋 Обзор проекта

EXMACHINA-AI — это система для автоматизации производственной логистики, которая:

- **Диагностирует процессы** — не лечит симптомы, а находит корневые причины
- **Прогнозирует события** — предупреждает сбои раньше, чем они произойдут
- **Синхронизирует цепи поставок** — видит материальные потоки и операции как единый организм
- **Работает детерминированно** — без галлюцинаций, с полным контролем контекста

## 🚀 Развёртывание

Сайт автоматически развёртывается через GitHub Pages при пуше в `main`:

```bash
git add .
git commit -m "feat: описание"
git push origin main
```

Обновится на https://exmachina-ai.ru через 30-60 секунд.
